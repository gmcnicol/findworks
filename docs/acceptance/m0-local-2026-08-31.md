## Defects found during real-client acceptance

- Codex repeats the OAuth `resource` parameter. The authorisation endpoint now validates every supplied value instead of misbinding the list.
- Real harness access expired after 15 minutes. Rotating, hashed 30-day refresh tokens now preserve login while one-time reuse and whole-grant revocation fail closed.
- Direct unresolved exports could produce `#evidence-null`. Export now coalesces direct and joined Evidence identities and omits the Evidence object only when none exists.
- The worker ignored `SPRING_FLYWAY_ENABLED=false`. Custom Flyway configuration now honours it.
- Stale email-delivery leases were never reclaimed. Expired leases now return to the queue, and provider calls carry the durable outbox identity as an idempotency key.
- Docker runtime launch omitted `-i`, so Pi never received context. Runtime launch now attaches standard input.
- Killing a timed-out Docker client could leave the runtime container alive. Each run now has an exact name and is forcibly removed on every exit path.
- The production worker had no route to managed PostgreSQL. It now joins the outbound egress network while Pi runtime children remain on the internal runtime network.
- Operator status counted a nonexistent email-delivery state and omitted live leases. It now counts both pending and running email work, with a regression test.
- Discovery purge left the standalone retention-warning email outbox row, including encrypted recipient data. Purge now removes it before deleting the Discovery graph.
- Operator status reads were unaudited. Successful reads now write a content-free audit event.
- Structured answers accepted only three hard-coded option identifiers. Submission now resolves the selected option from the active Question, and runtime-created modes always receive validated canonical options.
- Findings Packages could only be accepted. Investigators can now accept with optional notes or reject the exact READY version with required follow-up; either terminal decision starts retention, while only acceptance publishes reviewed context.
