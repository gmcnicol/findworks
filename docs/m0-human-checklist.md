# M0 human acceptance checklist

Record pass or fail only. Put substantive Investigator notes in the exact Findings Package decision, not this checklist.

- [ ] Investigator and external expert are different authorised humans using separate browsers.
- [ ] Purpose, boundaries, expected commitment, data use, retention, contact route, and right to stop were accurate and visible before Begin.
- [ ] Shaping follow-ups depended on the Investigator's answers, exposed real vagueness, and invented no authority or fact.
- [ ] Interview follow-ups used the expert's vocabulary or new information, avoided answered ground, skipped irrelevant guidance, respected decline and ownership limits, and refused premature completion.
- [ ] Investigator checked every current Knowledge Item and unresolved outcome against exact Evidence context, attribution, source, and offsets; any fabrication or misrepresentation is an automatic failure.
- [ ] Investigator reviewed or corrected every required item and accepted the exact Findings Package with meaningful notes.
- [ ] Keyboard navigation, visible focus, validation errors, informed start, pause/resume, 200% zoom/reflow, and state interpretation allowed completion. Cosmetic preference alone did not fail acceptance.
- [ ] No private context, internal prompt/tool/model detail, foreign Discovery data, token, or credential appeared.
- [ ] No direct database edit, release change, coaching script, or synthetic human response occurred during the live pilot.
