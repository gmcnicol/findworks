# FindWorks

FindWorks helps Investigators learn what they need to know from other people. The broader domain vocabulary is defined in [CONTEXT.md](./CONTEXT.md).

## Language

**Runtime Turn**:
One bounded step in an Interview Session in which the interview agent proposes Evidence-linked outcomes and exactly one next action: ask a Question or propose completion. A Runtime Turn is not an interviewee answer or a completed Interview Session.
_Avoid_: model call, interview (when referring to a Runtime Turn)
